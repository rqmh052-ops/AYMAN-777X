# School Maze Horror V5 — بنية الملفات للسيرفر

## هيكل المجلدات المطلوب على السيرفر

```
/your-server-root/
│
├── index.html              ← ملف اللعبة الرئيسي (كل شيء داخله)
│
├── models/
│   ├── WEAM1.glb           ← مجسم العدو 1 (مطلوب)
│   └── WEAM2.glb           ← مجسم العدو 2 (مطلوب)
│
└── audio/
    └── enemy_sound.mp3     ← صوت العدو (اختياري - اللعبة تعمل بدونه)
```

---

## ملاحظات مهمة

### ملفات المجسمات
- ضع ملفي `WEAM1.glb` و `WEAM2.glb` داخل مجلد `models/`
- السيستم يضبط حجمهما تلقائياً ليناسب ارتفاع ~1.8 وحدة
- لو فشل التحميل، يظهر مجسم بديل مؤقت تلقائياً

### ملف الصوت
- ضع ملف `enemy_sound.mp3` داخل مجلد `audio/`
- إذا لم يوجد الملف، تعمل اللعبة بشكل طبيعي بدون صوت العدو

### المتطلبات
- سيرفر HTTP عادي (Apache / Nginx / Node static)
- لا يحتاج backend أو database
- يعمل على المتصفح مباشرة
- Three.js يُحمَّل من CDN تلقائياً
